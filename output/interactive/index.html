Read level 0 with care. Optimization level 0 pins the initial layout to TrivialLayout, the identity permutation — which happens to pre-align the line map with how these circuits index their qubits. It is a valid, declared Qiskit condition, but it partly measures physical-index alignment rather than connectivity alone, which is why it ships off by default here. Cairo's 24-qubit GHZ chain stays penalized at every level regardless: its longest simple path is exactly 21 nodes, so no static placement embeds a 24-qubit chain without routing.
